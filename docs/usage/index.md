# Developer Usage

This directory contains developer usage documentation for the Better Agent Terminal (BAT).

- Follow the project guidelines in `AGENTS.md` and `CLAUDE.md`.
- Use `pnpm run dev:renderer` to start the frontend.
- Use `pnpm run check:tauri-rust` and `pnpm run test:tauri-rust` for backend code changes.
- Refer to the main README for building from source.
